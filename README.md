# Career College Frontend

Production-ready frontend foundation for a career college website.

## Tech Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- shadcn/ui-ready configuration
- GSAP for motion

## Run Locally

1. npm install
2. npm run dev

Open http://localhost:3000.

## Available Scripts

- npm run dev
- npm run build
- npm run start
- npm run lint

## Project Structure

- public/ for static assets
- src/app/ for layout, page entry, and global styles
- src/features/ for domain-focused UI and logic
- src/components/ui/ for shadcn-style shared components
- src/lib/ for helpers like cn() and GSAP setup
- docs/architecture/ for structure guidelines
